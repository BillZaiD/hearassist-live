# HearAssist Live

تطبيق أندرويد تجريبي للمساعدة على السمع **HearAssist Live**، يلتقط صوت الميكروفون ويعالجه في الوقت الفعلي ويُعيد تشغيله عبر السماعات السلكية أو USB-C مع إمكانية تعديل الترددات يدوياً.

> **تنبيه مهم:** هذا التطبيق تجريبي وليس جهاز سمع طبي معتمد، ولا يستبدل أجهزة السمع الموصوفة طبيًا. يرجى قراءة تنبيهات السلامة داخل التطبيق.

## المزايا
- **معالجة في الوقت الفعلي** – حلقة صوت مباشرة مع خيط مخصص عالي الأولوية
- **معادل ترددات بـ 9 نطاقات** – `125Hz` حتى `8kHz` مع تعديل دقيق بالديسيبل
- **إعدادات مسبقة** – *وضوح الكلام* و*بيئة هادئة*
- **محدد صوت ذكي** – لمنع التشوه الرقمي
- **واجهة احترافية ومنسقة** – مصممة بعناية مع دعم كامل للعربية واتجاه RTL
- **حفظ الإعدادات** – يتم حفظ المعادل ومستويات الصوت تلقائياً
- **خدمة أمامية** – يعمل مع إشعار واضح أثناء الاستماع
- **أمان افتراضي** – يبدأ بمستوى صوت منخفض، ومحدد مفعل دائمًا

## متطلبات التشغيل
- أندرويد 10 فما فوق (`Android 10+`)
- إذن الميكروفون `RECORD_AUDIO`
- يفضل استخدام **سماعات سلكية** أو **USB-C** للحصول على أداء أفضل
- بعض الأجهزة لا تدعم التقاط الميكروفون وتشغيل الصوت معًا بشكل موثوق

## طريقة البناء

### الطريقة 1: GitHub Actions (أسهل وأسرع)
1. ارفع مجلد `hamza app/` إلى مستودع GitHub
2. سيقوم العمل التلقائي `Build APK` ببناء ملف APK
3. بعد الانتهاء، يمكنك تحميل الملف من تبويب **Actions > Build APK > Artifacts** باسم `HearAssist-Live-Debug`

### الطريقة 2: Android Studio
1. افتح مجلد `hamza app/` في Android Studio
2. انتظر مزامنة Gradle
3. شغّله على جهاز فعلي أو ابنِ APK

### الطريقة 3: سطر الأوامر مع Gradle Wrapper
```bash
./gradlew assembleDebug
```
سيكون الملف موجودًا في:
```
app/build/outputs/apk/debug/app-debug.apk
```

## هيكل المشروع
- `app/src/main/java/com/hearassist/live/audio/` – محرك الصوت ومعالجة الإشارة DSP
- `app/src/main/java/com/hearassist/live/ui/` – واجهة المستخدم بـ Jetpack Compose
- `app/src/main/java/com/hearassist/live/service/` – خدمة التشغيل الأمامية
- `app/src/main/java/com/hearassist/live/data/` – حفظ الإعدادات بـ DataStore

## تنبيهات السلامة
- **ليس بديلاً عن أجهزة السمع** – هذا التطبيق تجريبي ولا يمكنه استبدال الأجهزة الطبية
- **ابدأ بصوت منخفض** – التطبيق يبدأ بمستوى منخفض لأسباب السلامة
- **توقف فورًا** إذا شعرت بعدم الراحة، ألم، طنين، دوار، أو تفاقم في الأعراض
- **استشر أخصائي سمع** في حالة وجود فقدان سمع كبير
- **القيم المعروضة بالديسيبل** رقمية وليست مقاسة صوتيًا فعليًا
- **الحماية السمعية غير مضمونة** رغم وجود المحدد

## قيود معروفة
- البلوتوث غير مضمون للعمل بزمن انتقال منخفض في الوقت الفعلي
- بعض أجهزة OEM تقيد التوجيه الصوتي
- تقليل الضوضاء والضغط الديناميكي في النسخة الحالية معطّلان كميزات تجريبية
- زمن التأخر يختلف حسب الجهاز
- لا يوجد تسجيل أو بث صوت عبر الإنترنت
